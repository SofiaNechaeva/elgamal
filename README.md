# Учебная цифровая подпись Эль-Гамаля с Tkinter

## Запуск

Требуется Python 3.10+ с установленным Tkinter. Сторонних Python-пакетов нет.

```bash
python main.py
```

В Linux, если `import tkinter` не работает, установите системный пакет `python3-tk`.

## Порядок работы

1. В верхней панели укажите `p=23` для ручного учебного примера или очистите поле `p`, чтобы сгенерировать простое число заданной битности. Нажмите «Сгенерировать заново».
2. В левой панели (А) введите сообщение и нажмите «Подписать и отправить».
3. Правая панель (Б) автоматически получит пакет из очереди, покажет сообщение, подпись и полную проверку `c₁=y^a·a^b mod p`, `c₂=A^m mod p`.
4. Измените текст в правой панели и нажмите «Проверить изменённый текст» — подпись должна перестать проходить проверку (кроме крайне маловероятных совпадений в маленьких учебных группах).
5. Открытый и закрытый ключи хранятся в `keys/public.json` и `keys/private.json` соответственно. Файлы появляются при генерации.

## Формулы

`y=A^xᵢ mod p`; `a=A^k mod p`; `m=int(SHA-256(M))`; `gcd(k,p-1)=1`; `b=k⁻¹(m−xᵢa) mod (p−1)`; проверка `c₁=y^a a^b mod p`, `c₂=A^m mod p`, `c₁==c₂`.

Формулы и подстановки выводятся в двух отдельных панелях: заголовки, формулы, числовые подстановки и результат выделены разными стилями. Для очень больших чисел строки переносятся автоматически; Matplotlib или LaTeX не требуются.

## Структура

- `crypto/elgamal.py`: арифметика, генерация ключей, подпись, проверка и журналы вычислений.
- `crypto/number_provider.py`: **заменяемые** `random_integer`, `is_prime`, `generate_prime`, `distinct_prime_factors`, `generate_prime_with_factors`.
- `crypto/key_store.py`: сохранение и загрузка ключей.
- `communication/transport.py`: интерфейс `Transport` и реализация `LocalTransport` с очередью.
- `communication/packet.py`: сериализация пакета в байты JSON: сообщение — Base64, `h(M)` — SHA-256 в hex, большие числа — десятичные строки.
- `application/services.py`: логика отправителя и получателя, не зависящая от Tkinter.
- `ui/app.py`: интерфейс.
- `tests/test_project.py`: автоматические тесты.

## Ограничения учебной версии

- Ключ `private.json` хранится без шифрования. Не пересылайте его Б.
- Генератор простых использует безопасные простые `p=2q+1`; тест Миллера—Рабина вероятностный для больших чисел. Эти функции специально вынесены для замены товарищем.
- `key_id` — лишь метка, не доказательство принадлежности ключа. Для реального сетевого обмена нужна аутентификация открытого ключа.
- У алгоритма классического Эль-Гамаля есть тонкости выбора параметров и проверок, поэтому эта программа предназначена для обучения, не для защиты реальных данных.
- При выборе маленького p возможны случайные совпадения при проверке подменённого сообщения, поскольку хеш сравнивается в группе порядка p−1.
- Формулы выводятся в текстовом виде с математическими символами, без дополнительной библиотеки рендеринга.

Источник чисел: счётчики процессора Windows (`Get-Counter`) или статистика процессора Linux (`/proc/stat`). Их значения считываются один раз за процесс и используются для генерации последовательности SHA-256. Счётчики не гарантируют криптографическую непредсказуемость ключей и подписей; эта реализация предназначена только для обучения.
